# Звіт про UI-тестування проєкту «Student Assistant»

## Підсумок тестування
- **Інструмент тестування:** Google Chrome DevTools (Device Mode — режим Responsive, Console, Network, Performance).
- **Перевірений діапазон ширин:** від 320px до 1920px (7 контрольних точок).
- **Виявлено та виправлено дефектів:** 1 (навчальний дефект горизонтальної прокрутки на ширині 320px через `min-width: 400px` у `.task-card` — виправлено видаленням фіксованої мінімальної ширини). Регресійних дефектів верстки та помилок у консолі не виявлено.

## Результати перевірки на контрольних ширинах

| Ширина | Орієнтир | Колонок | Дефекти |
|--------|---------------------|---------|---------|
| 320 | малий смартфон | 1 | Виявлено й виправлено горизонтальну прокрутку через `min-width: 400px` у `.task-card` |
| 375 | iPhone SE | 1 | Дефектів не виявлено |
| 600 | межа tablet | 2 | Дефектів не виявлено |
| 768 | iPad (портрет) | 2 | Дефектів не виявлено |
| 1024 | межа desktop | 3 | Дефектів не виявлено |
| 1280 | ноутбук | 3 | Дефектів не виявлено |
| 1920 | десктопний монітор | 3 | Дефектів не виявлено |
